# 🐸 Frogger Clone (Godot)
A work-in-progress Frogger-style game built with Godot Engine — created while learning from a YouTube tutorial series.

This project is part of my game development learning journey. It uses starter assets provided by the tutorial creator, and all credit goes to them. (Clear Code on YouTube)

## 🎮 About
I’m learning how to use Godot by following this tutorial and adapting it into my own Frogger-style game. The goal is to understand core Godot concepts like:
- Scene system & instancing
- Player movement & input
- Collision detection
- Level design
- UI & HUD
- Audio & feedback

Expect this repo to evolve as I learn more!
